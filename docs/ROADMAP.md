# Roadmap

[Project](../README.md) · [Contributing](../CONTRIBUTING.md)

This is a prioritized direction, not a delivery-date promise. The current public release is [0.3.0](https://github.com/hypery11/muse-gadget-everywhere/releases/tag/v0.3.0), with universal and modern APKs using development signing.

## Make the first success easy

- Task-based native controls, clear connection state and guided pairing.
- TV remote focus, phone touch layout and readable large-text behavior.
- Short, accurate install instructions and real screenshots.
- A reproducible demonstration of a local card, followed by a Muse cloud command.

## Broaden the evidence

- Physical Android phones and tablets, especially BLE peripheral behavior.
- Real Home Assistant and MQTT integration reports.
- A 72-hour connected soak with measured reconnect and memory behavior.
- More OEM background-service and reboot testing.

[Submit a device report](https://github.com/hypery11/muse-gadget-everywhere/issues/new?template=device_report.yml) to help this stage.

## Prepare the next release

- Complete native dependency remediation and review build provenance.
- Establish production signing and documented update continuity.
- Preserve clearly named universal/modern artifacts, checksums and release notes for each version.
- Keep release screenshots and feature descriptions aligned with the downloadable version.

## Grow useful examples

- Tested scene recipes with expected results and prerequisites.
- Community-maintained translations and device setup notes.
- Public, reproducible demos built from reported user needs.

Ideas are welcome in [Discussions](https://github.com/hypery11/muse-gadget-everywhere/discussions). Core constraints remain: no root requirement, unchanged upstream SDK, explicit hardware permissions and honest command status.
